Git : It is a version control system which records file changes and allows to move safely between versions<br>
GitHub : Remote website that hosts git repositories and support team collaboration, project history, Pull requests and  review<br>
git init : create an empty git repository or reinitialize an existing one<br>
git clone : copy remote repository into local machine<br>
git status : see changed, staged and untracked files <br>
git add . : stage all changes in the current directory<br>
git commit -m "message" : create a commit with meaningful message<br>
git push origin main : upload the changes from local machine to github(remote)<br>
