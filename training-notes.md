Git : It is a version control system which records file changes and allows to move safely between versions
GitHub : Remote website that hosts git repositories and support team collaboration, project history, Pull requests and  review
git init : create an empty git repository or reinitialize an existing one
git clone : copy remote repository into local machine
git status : see changed, staged and untracked files 
git add . : stage all changes in the current directory
git commit -m "message" : create a commit with meaningful message
git push origin main : upload the changes from local machine to github(remote)
